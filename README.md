# e-VOLT Chile

Página web de e-bikes para Chile, creada a partir del brief e información del producto.

## Publicación

GitHub Pages publica main desde la raíz. El archivo index.html incluye estilos, interacciones y fotos originales del proveedor; no requiere instalación ni compilación.

## Incluye

- Catálogo V8 y XDC-06 con fichas técnicas.
- Comparador con filtro de diferencias.
- Diseño adaptable, navegación móvil y preguntas frecuentes.
- Generador de solicitudes de cotización descargables.

## Pendiente para activar ventas

Confirmar precios finales en CLP, disponibilidad, despacho, garantía y contacto comercial. Conectar la recepción de consultas y, si corresponde, un proveedor de pagos. El formulario actual no envía datos ni procesa pagos o reservas. Confirmar configuración y clasificación de las unidades para su uso en Chile.

No se publican costos de importación ni datos privados de la factura.
